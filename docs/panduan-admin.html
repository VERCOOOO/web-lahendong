Mulai dari sini

Enam aturan yang berlaku di semua tab

Ingat keenam hal ini, dan hampir semua pekerjaan admin jadi jelas.

Satu baris = satu data

Satu destinasi, satu aparat, satu lingkungan. Urutan baris di sheet = urutan tampil di situs.

Kolom pertama wajib diisi

Baris yang id (atau kunci) kosong tidak ditampilkan. Kosongkan id untuk menyembunyikan data tanpa menghapusnya.

Sel kosong = disembunyikan

Situs tidak pernah mengarang isi. Telepon kantor kosong? Barisnya tidak muncul sama sekali.

Jangan ubah nama tab & baris judul

Situs mencari tab berdasarkan namanya (wisata, aparat, …) dan kolom berdasarkan judulnya.

Semua sel berformat Teks biasa

Biarkan begitu. Tanpa itu Google bisa membuang angka 0 di depan nomor telepon, atau membuat nilai hilang diam-diam.

Satu orang, satu baris

Aparat cukup ditulis sekali di tab aparat. Halaman Pemerintahan, Beranda, dan Kontak semuanya membaca dari sana.

Pekerjaan sehari-hari

Cara melakukan…

Langkah untuk tugas yang paling sering. Kartu bergaris putus-putus perlu bantuan pengembang karena menyentuh berkas situs.

Mengganti pejabat (mis. Lurah baru)

  1. Buka tab aparat, cari baris jabatannya (Lurah = A1).
  2. Ganti isi kolom nama. Id, jabatan, dan atasan dibiarkan.
  3. Muat ulang situs.

Berubah di: bagan & profil (Pemerintahan), blok pimpinan (Beranda), dan Kontak bila nomornya diisi.

Menambah aparat ke bagan

  1. Tab aparat → isi baris baru dengan id baru, mis. A4.
  2. Isi nama, jabatan, dan urutan (angka urut tampil).
  3. Isi atasan dengan id orang di atasnya, mis. A1 (Lurah) atau A2 (Sekretaris).

Bagan otomatis menambah kotak di bawah atasannya. Atasan kosong = kotak berdiri di puncak.

Menampilkan nomor aparat di Kontak

  1. Tab aparat → isi kolom nomor orang tersebut, pakai tanda hubung: 0812-3456-7890.
  2. Muat ulang halaman Kontak.

Muncul di kelompok “Aparat kelurahan”. Jangan tambahkan orang yang sama di tab kontak.

Menambah nomor darurat atau layanan umum

  1. Tab kontak → baris baru dengan id baru, mis. K4.
  2. Isi nama (Puskesmas Tomohon Selatan), peran, dan nomor.
  3. Isi kategori: darurat atau umum.

Tampil di kelompok Darurat atau Layanan umum pada halaman Kontak. Tanpa nomor = tidak ditampilkan.

Memperbarui data penduduk tahunan

  1. Tab statistik → ganti tahun_data, jumlah_penduduk, laki, perempuan, jumlah_kk.
  2. Tab lingkungan → ganti angka tiap lingkungan.
  3. Cek: jumlah jiwa semua lingkungan = jumlah_penduduk, dan laki + perempuan tiap baris = jiwa.

Grafik, tabel, dan baris total di halaman Penduduk dihitung ulang otomatis.

Mengubah jam layanan, alamat, atau telepon kantor

  1. Tab profil → cari kunci-nya (jam_layanan, alamat_kantor, telepon_kantor, email).
  2. Ganti kolom nilai saja.

Satu kali ubah, tampil di bilah atas, footer, halaman Kontak, dan halaman Layanan sekaligus.

Menambah destinasi wisata

  1. Tab wisata → baris baru, id W5. Isi minimal nama, ringkas, deskripsi.
  2. Kolom lain boleh kosong — bagiannya tidak ditampilkan.
  3. Rute bertahap: satu langkah per baris dalam sel cara_kesana.

Muncul di Wisata, Galeri, dan halaman detail wisata-detail.html?id=W5. Tanpa foto terdaftar, kartunya memakai gambar pengganti. Susunan kartu menyesuaikan jumlahnya sendiri (maks. 4 per baris: 5 kartu → 3 + 2, 6 → 3 × 2, 8 → 4 × 2).

Menambah potensi atau UMKM

  1. Potensi: tab potensi → id P5, judul, deskripsi (boleh beberapa paragraf).
  2. UMKM: tab umkm → id U1, nama, produk, kontak, lingkungan.

Potensi tampil di halaman Potensi dan Beranda (kalimat pertamanya saja). UMKM tampil di Potensi dan Galeri.

Menyembunyikan sementara

  1. Kosongkan kolom id baris itu (tab profil/statistik: kosongkan kunci).
  2. Untuk menampilkan lagi, isi kembali id yang sama.

Datanya tetap tersimpan di sheet, hanya tidak dibaca situs.

Mengganti atau menambah foto

  1. Simpan foto (format .webp, lebar maks. 1600px) di folder img/.
  2. Daftarkan di assets/js/komponen.js, bagian FOTO: W5: "nama-file.webp".
  3. Commit & push.

Foto sengaja tidak diatur dari spreadsheet pada iterasi ini.

Memasang peta wilayah (PNG)

  1. Simpan gambarnya sebagai img/peta-wilayah.png.
  2. Commit & push.

Halaman Profil menampilkannya otomatis di atas peta Google. Selama berkasnya belum ada, bagian itu disembunyikan.

Kondisi saat ini

Mana yang sudah asli, mana yang belum

Nilai yang belum ada data resminya ditandai CONTOH di kolom keterangan pada sheet. Semuanya perlu beres sebelum situs diumumkan.

Sudah data asli

  • statistik & lingkungan — Kelurahan Lahendong, 2026
  • aparat — Lurah, Sekretaris Kelurahan, Kasi Pemerintahan
  • wisata — 4 destinasi
  • potensi — 4 potensi
  • kontak — nomor darurat nasional 110, 113, 119

Masih contoh — ganti

  • Legenda & sejarah — tulisan sementara, bukan tuturan warga
  • Jam layanan, luas, ketinggian, suhu
  • Batas wilayah (utara, selatan, timur, barat)
  • Syarat, alur, waktu & biaya di tab layanan
  • Semua foto — masih ilustrasi pengganti

Masih kosong

  • Telepon & email kantor
  • Nama kepala lingkungan (8)
  • Nomor aparat
  • Data UMKM
  • Peta wilayah PNG

Perlu disalin ke sheet

  • Tab lingkungan, Lingkungan 2: jumlah_jiwa → 328 (172 + 156)
  • Tab lingkungan, Lingkungan 7: jumlah_jiwa → 222 (109 + 113)
  • Tab statistik, sumber_data → Kelurahan Lahendong
  • Sudah benar di template & data contoh; setelah disalin, total tabel = ringkasan = 2.235

Untuk pengembang

Hanya perlu dibaca bila mengubah kode, foto, atau susunan kolom. Penjelasan teknis lengkap ada di Panduan Teknis.

Susunan berkas dan cara menerbitkan 
*.html                satu berkas per halaman — markup saja
assets/css/style.css  sistem desain (palet, tipografi, komponen, bagan)
assets/js/data.js     PAKAI_DUMMY, ID_SPREADSHEET, SKEMA tab, ambilData()
assets/js/data-contoh.js  data awal = isi template sheet
assets/js/ui.js       header, footer, info kantor, animasi, status memuat
assets/js/komponen.js FOTO statis + potongan HTML bersama
assets/js/halaman/    logika per halaman (index.html → beranda.js)
data/template-data-lahendong.xlsx  template spreadsheet

Menambah kolom atau tab: tambahkan di SKEMA (data.js) dan data-contoh.js, buat ulang template, perbarui sheet lebih dulu, baru commit & push. Urutan ini mencegah situs live sempat menampilkan “belum bisa dimuat”.

Tanpa sheet: ubah PAKAI_DUMMY menjadi true di data.js — situs memakai data-contoh.js.

Pratinjau lokal: jalankan python3 -m http.server di folder repo, lalu buka http://localhost:8000.

Panduan ini disimpan di repo sebagai docs/panduan-admin.html. Bila susunan tab berubah, perbarui panduan ini bersama README dan tab petunjuk di spreadsheet.
